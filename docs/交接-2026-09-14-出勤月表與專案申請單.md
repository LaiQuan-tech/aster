## 2. 出勤月表流程（P1）
- 資料：`attendance_sheets`（一人一月）＋ `attendance_sheet_days`（整月每天一列；計算欄重建、人工欄保留；覆寫必附原因 CHECK；禁刪＋稽核）。
- 狀態機：`draft → submitted → manager_reviewed → approved → locked`，`returned`／`reopen`。核准時凍結 `snapshot`（含 `payrollDays`），薪資 run 讀快照，finalize 後 `locked`。
- 經理＝員工部門主管（`managerOfEmployee`，往上找）；無主管直接到 HR。送出時日級 error 異常須填 `anomaly_ack`（`payroll.requireAnomalyAck`）。
- 每月 1 日 05:00 台北 worker 呼叫 `/internal/attendance-sheets/generate` 產上月月表（worker 在 Railway，記得 `railway up`：這次 worker.ts 改了排程清單，**尚未重新部署**——見 §6）。
- 端點：`routes/attendance-sheets.ts`（generate／list／:id／my／PATCH days／submit／review／approve／return／reopen／recompute）、`routes/exports.ts`（xlsx）。
- 前端：`components/AttendanceSheetTable.tsx`（兩端共用）、`/ess/attendance-sheet`（＋待我審核）、`/admin/attendance-sheets`、`/admin/attendance-sheets/[id]`（列印用 `window.print()`，`@media print` 在 globals.css）。

## 3. 專案申請單（P3）
- 編號 `AT-{民國年}-{NNN}`（`project_settings.code_prefix/code_year_style/code_seq_digits`）；`POST /projects/reserve` 預先取號；`kind main|change|addition|advance`＋`parent_project_id`（子案新號、不進母案分母）。
- 金額口徑一律**未稅**：未稅＝合約總額（`contractTotal()`，無合約取最新報價單並標 `amountSource:'quotation'`）、稅＝×`vat_rate`、含稅；已請／已開票／已入帳／未收；利潤＝未稅−發包−其他支出。
- 期款事件：`POST /billings/:id/{invoice,uninvoice,receive,unreceive}`（順序不阻擋只 `warnings`；已入帳凍結金額）；`kind guild_advance` 不進尾差。
- 副委託：`project_subcontracts`＋`project_subcontract_payments`（代扣 `amount>20000 ? ×0.10`；放款公司、收據抬頭＝`companies`）。
- 三段權限：`GET /projects/:id` 回 `access:{finance,bonus}`；非 finance 者 `money:null, billings:[], subcontracts:[]`。
- 年度總表 `GET /projects/annual?year=115&format=xlsx`、未收款 `GET /projects/receivables`；前端 `/admin/projects/annual`、`/admin/projects/receivables`、`/admin/projects/[id]/application`（列印）、`/admin/clients`、`/admin/companies`。
