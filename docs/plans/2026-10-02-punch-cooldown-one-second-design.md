# 打卡冷卻一秒設計

## 目標

將一般員工 `POST /punch` 的預設防連按冷卻時間由 60 秒調整為 1 秒，讓上下班卡可在一秒後再次操作，同時保留防止同一瞬間重複寫入的保護。

## 行為

- 未設定 `PUNCH_COOLDOWN_SECONDS`、空字串或無效數字時，採用 1 秒。
- 正數環境變數仍可覆寫預設值。
- `0` 或負數仍代表停用冷卻。
- 冷卻區間維持半開區間：距上一筆打卡未滿 1 秒時回 `409 punch_too_soon`，滿 1 秒即可打卡。
- HR 人工補登仍不受冷卻限制。
- 前端成功後的 3 秒視覺鎖定維持不變；本次只調整 API 防重複寫入的預設值。

## 驗證

先修改單元測試期待預設值為 1，確認舊實作下測試失敗，再修改常數。驗證預設解析、邊界判斷、API 打卡守門測試與型別檢查，並同步更新交接文件。
