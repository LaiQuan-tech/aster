## 為什麼 migrations 被停用

那套是在拿到 aster repo **之前**平行設計的。既然 aster 已經有可運作的
schema、引擎和測試,兩套並存只會分岔。保留是為了 **E/F/G/L 區塊**
(合約、應收帳款開票、外包請款、集團代收代付)——那四塊 aster 目前沒有,
之後要移植過來時看這份比重寫快。

`02-資料模型-v0.md` 同理:當設計參考讀,不要當成現況。
**現況以 `aster/supabase/` 為準。**
